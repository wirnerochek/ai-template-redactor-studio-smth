# ai template & edit studio

## проблема
при создании аватарок, баннеров для youtube или обоев под телефон, планшет и пк приходится вручную подбирать размеры, искать картинки и использовать несколько разных программ для базовой обработки

## решение
веб-приложение на базе ai, которое генерирует изображение по текстовому описанию сразу под выбранный шаблон устройства или профиля, позволяет наложить фильтры и добавить подпись в одном окне

## что умеет mvp
1. генерация изображений с помощью ai по текстовому описанию под готовые шаблоны (аватарка 1:1, баннер youtube, пк, tv, планшет, смартфон, смарт-часы)
2. обработка сгенерированного фото фильтрами (черно-белый, размытие, яркость, контраст, инверсия) и добавление текстовой подписи
3. мгновенный предпросмотр и скачивание готового шаблона в формате jpeg
